# Security policy

Security fixes target the 0.1.x release line. The supported backup engine for v0.1.0 is restic 0.20.0.

Please report suspected vulnerabilities privately to the repository maintainers using GitHub's **Security → Report a vulnerability**. If that control is unavailable, open an issue titled “Private reporting contact requested” with no technical details and wait for a private channel before sharing the report. [Repository security page](https://github.com/IILEGENDII/research-backup-auditor/security)

Include the affected version, OS, expected and observed outcomes, and the smallest owner-controlled synthetic case that demonstrates the problem. Remove credentials, personal paths, hostnames, repository identifiers and sensitive research material. Use only your own disposable test directories. Coordinate publication with maintainers. No response time is guaranteed.
